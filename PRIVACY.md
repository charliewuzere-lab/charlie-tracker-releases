# Privacy policy

This is a private, single-user desktop app. It is not offered to the public.

- All data is stored locally on the user's own computer, encrypted.
- Google Drive access uses the drive.file scope only: the app can see only the backup files it creates itself.
- Backups uploaded to Google Drive are encrypted before upload.
- No data is sold, shared, or sent to any server run by the developer. There is no telemetry.
- Access can be revoked at any time at https://myaccount.google.com/permissions
